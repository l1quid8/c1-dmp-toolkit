# v1.5.1 — RISER hardware forms and independent cable callouts

## Changes

- Add Device in RISER launches the existing 710 splitter, keypad, and RSP/paired
  power-supply dialogs. New equipment enters Unplaced without moving existing items.
- Edit Device / device double-click opens the existing domain card in a modal.
  Edits apply immediately across the project; Done explicitly commits a pending
  splitter number. MSP editing exposes its location, not removal or duplication.
- Remove from Project retains existing hardware/zone-cascade confirmations.
  Hardware forms retain domain history behavior (not a canvas Undo command).
- Callouts have independent selection, incremental drag, keyboard nudging,
  double-click text editing, Hide/Restore Label, and Reset Label Position.
  Delete on a callout hides only the text; wire deletion remains a confirmed
  electrical disconnect. Empty custom text restores automatic cable text.
- Callout changes support Undo/Redo and Escape; pending gestures are cancelled
  before undo/redo, label deletion, or nudging. Hidden labels survive full
  Preview/Apply layout replacement; that explicit operation resets positions.
- Moved/hidden callouts persist through save/reopen, route reattachment, SVG,
  and both PDF profiles. Visible off-page labels trigger warnings.
- Popup menus restore actual wiring after rejection, dependent keypad fields
  update together, and project teardown closes owned hardware dialogs.

## Compatibility and rollback

Saves now use schema 6 so older applications reject files whose independent
callout visibility they cannot preserve. Schemas 1–5 remain readable; pre-feature
labels default visible with their original offsets. Keep original project copies
when testing. Roll back using the prior native app and a pre-schema-6 project copy.
