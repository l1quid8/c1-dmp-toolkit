# v1.4.5 — Project-wide equipment location rename

- Select a RISER location module and choose **Rename location globally…**, or
  double-click the module. The inspector displays the readable location name
  with wrapping instead of clipping the internal identifier.
- Preview the affected equipment before confirming. The rename updates SITE,
  SPLITTERS, KEYPADS and POWER, including unplaced matching hardware and paired
  RSP power supplies. Existing MSP aliases and service-keypad suffixes are
  handled without relying on RSP numbers to infer room assignments.
- Joining an existing location requires explicit confirmation. Geometry,
  electrical connections and cable routes do not move. Normal validation still
  reports equipment that sits outside a combined location frame.
- Undo/redo restores only the location fields changed by that command. External
  location edits invalidate conflicting rename history even before a debounced
  refresh runs; ordinary markup undo does not overwrite external room edits.
- Save/reopen and newly generated worksheets retain the shared locations. Door
  charts must be regenerated from the updated worksheet. Arbitrary zone
  descriptions are not search-and-replaced.
- Building-based/electrical-first layout is a separate design discussion and
  is not enabled in this release. No persistence schema change is required.
