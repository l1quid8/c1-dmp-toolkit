# v1.6.0 — Approved riser presentation

## Changes

- Shared Canvas/SVG/PDF schematic keypad faces, chamfered 710 bodies and
  clear MSP/RSP hierarchy. Standard 710 bodies are 210 × 135 master points:
  25% narrower/shorter than the first visual sample. Captions remain inside.
- Longer locations wrap and grow detailed bodies as needed; classic saved
  geometry is retained. Electrical ports reattach when a detailed body grows.
- New scenes and Preview layout use deterministic electrical-first placement,
  with the service keypad left of MSP, separated KP/LX branches and dense-row
  packing. No device, location, zone range or electrical connection is inferred
  from the style-reference drawing.
- The MSP KP BUS remains on its left midpoint. Active bottom ports are spread
  across the panel; Connect mode exposes and names unused LX ports.
- Location frames are hidden by default in the new style. The Locations layer
  explicitly controls their printed visibility and supports Undo/Redo.
- Structured C1 title-block cells and sheet border; generic symbols do not
  claim an unrecorded hardware model. SVG remains standalone; PDFs searchable.
- Existing saved drawings retain classic symbols/positions until Preview
  layout → Apply layout. Apply is undoable. Manual callout visibility survives.
- Schema 7 reads schemas 1–6. Older apps reject new saves normally; retain
  original projects for rollback. No new runtime dependency.
