## Project compatibility and rollback

Back up original `.dmps` files before upgrading. Schema-3 projects intentionally cannot be opened by older schema-2 apps: those apps cannot preserve both features. If a release has a blocking regression, retain the schema-3 project, restore the prior app and the pre-upgrade project copy, and do not attempt to downgrade by editing `schema_version` manually.

Block publication if either editor is missing, saved data disappears, account verification fails, or any generated drawing/chart loses devices. A passing Python test suite is not a substitute for Windows package, RemoteLink import, or Excel print-preview checks.

## Review findings addressed

- Exact legacy splitter-ID collisions are rejected before they can overwrite a placement or turn a cable into a self-loop.
- Canonical wiring is preserved when the drawing has not yet been initialized, including deletion of the last imported connection before save/recovery.
- Legacy text refresh cannot overwrite an initialized graph or discard duplicate-port draft cables.
- Wiring edits and undo/redo invalidate review; drawing-only edits do not.
- The footer wraps at narrow widths, with the issue sheet kept above its actual height.
- Clearing an unmodeled wiring note marks the project dirty even when the canonical connection graph is unchanged; repeating the clear remains a no-op.
- RemoteLink keypad programming changes preserve riser Undo history while still updating validation and the receipt. Actual topology changes still invalidate stale history.

## Packaging note

The preview uses PyInstaller's ad-hoc signature, not Developer ID signing or notarization.
