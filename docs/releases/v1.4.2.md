# v1.4.2 — Riser drag performance

- Move devices, their ports, location groups, and markup using existing canvas items instead of rebuilding the sheet on every pointer event.
- Update only affected cables during a drag. Bridge hops are recomputed when the gesture finishes; electrical connections remain unchanged during previews.
- Resize and cable-bend previews leave stationary grid, title-block, and device items intact.
- Skip duplicate snapped positions, avoid rebuilding validation when selecting an item, and perform one final redraw on drop.
- Coalesce rapid mouse motion into one pending frame using the latest pointer position; clear queued motion on drop, Escape, or widget destruction.
- Commit the latest mouse-up position, even when no matching motion event arrived. Escape and undo retain their existing restore semantics.
- Translate internal group cables directly rather than routing them twice and then discarding those routes.

Regression coverage includes stationary canvas identity, moved ports and attached cables, mouse-up position, one-step undo, Escape restoration, resize/markup/route previews, and internal-cable routing avoidance. Riverside's saved project is used read-only for local performance measurements.
