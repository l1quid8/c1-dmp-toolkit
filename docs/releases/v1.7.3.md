# C1 DMP Toolkit 1.7.3

## Changes

- Open a project normally when its crash-recovery copy is damaged or when Windows can't format the recovery time; the damaged copy is kept aside as `.recovery.unreadable`.
- Start a new project file when importing a design PDF, so a field-corrected project for the same school is never overwritten.
- Stop a worksheet, riser, or RemoteLink export when you choose Save and the save fails.
- Remember which worksheet a project generated, even after closing the app, so a door chart is built from the right file and warns when the project changed since.
- Offer "Regenerate worksheet first" when a door chart would use an out-of-date or unconfirmed worksheet; the finished door chart says which worksheet it came from.
- Check each update download against the checksum GitHub publishes, and install nothing if you cancel the save prompt before the update restarts the app.
- Show "Unsaved — auto-backup failed, save now" when crash protection can't write its backup.

## Validation

- Non-GUI regression suite: 836 passed, 260 skipped.
- Full regression suite with windows: 1,090 passed, 6 skipped.
- Worksheet fingerprint checked on two real worksheets (96 and 64 zones): unchanged through import, generation, save, reopen, and a second save/reopen.
- Native macOS app rebuilt, installed, and launched as C1 DMP Toolkit v1.7.3. A throwaway-folder check imported and saved a project, built a fresh door chart, regenerated a stale worksheet before the chart, and saved a second import as its own project file.
- GitHub CI now also runs the window-based tests on macOS and Windows. Those jobs run after this branch is pushed.
- Interactive Windows testing has not been performed locally.

## Compatibility

`.dmps` files gain an optional worksheet record; 1.7.2 and earlier still open them. Projects saved before 1.7.3 ask you to confirm the worksheet the first time you build a door chart.
