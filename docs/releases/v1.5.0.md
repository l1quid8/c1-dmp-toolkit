# v1.5.0 — Shared room locations and riser layout preview

- Stable Building/Floor/Room records drive physical room clusters. Imported
  text is retained until edited; matching building names or omitted floors
  never silently merge rooms. Unresolved equipment stays separately identified.
- New drawings use electrical-first clusters. Confirmed co-located head-end
  equipment shares the top-center cluster; remote rooms retain their actual
  identities. Dense layouts try tighter spacing without shrinking symbols.
- Existing saved drawings keep their layout. Preview layout is read-only;
  Apply replaces geometry as one undoable command, preserving title and markup.
  Changes to the project invalidate a stale preview. Generation is blocked
  until the preview is applied or cancelled.
- Location properties offer explicit shared Building/Floor/Room edits and
  distinct per-device reassignment. Merges require confirmation. Changes update
  other tabs and future worksheet output; regenerate the worksheet before a
  door chart. Device positions and electrical connections are not reassigned.
- Non-destructive Auto-layout protects retained devices and cables. Equipment
  that cannot fit remains in Unplaced. Legacy recovery remains version-aware.
- Canvas and vector output share wrapped heading geometry. Explicit Helvetica
  text attributes prevent the PDF converter falling back to Times. Cable-label
  clearance uses actual small-profile font metrics.
- Native File/Worksheet menus no longer scan project/output folders when
  opening. Recent projects come from the background-loaded cache; this removes
  a reproduced main-thread freeze on an unavailable folder.
- Saving upgrades projects to schema 5. Retain original project copies for
  older applications; v1.4.5 cannot open a newly saved schema-5 project.
