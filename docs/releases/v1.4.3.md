# v1.4.3 — Balanced risers and control audit

## Changes

- Default layout separates downstream location tiers, centers each row below the MSP, and preserves stable bus/output ordering. Wider module and cable corridors reduce crowding. Dense chains use balanced compact rows when full tiers would exceed the page; symbols are not shrunk.
- Generated cable routes protect location headings as well as device footprints. Cable labels seek space clear of other wiring, headings, symbols, and labels.
- Clear one- and two-bend Manhattan paths bypass the full routing search, retaining obstacle and occupied-lane checks while reducing drop-time recalculation.
- Existing saved geometry is not automatically replaced. Use **Re-layout All** to apply the new layout, with confirmation; title data and markup are retained and re-layout is undoable.
- Delete removes markup or confirms cable disconnection. For a device it opens the existing hardware-removal confirmation, including cascade warnings. Location modules and the required MSP explain why independent deletion is unavailable. Duplicate explains its markup-only scope.
- Undo/redo now synchronizes visible title-block fields, preventing a stale value from being saved again after undo.
- Non-finite font sizes and line widths are rejected before they can corrupt rendering.

## Verification scope

New editor-level tests cover toolbar Delete, hardware removal confirmation/cancellation and shared-topology cleanup, markup creation/duplication/arrangement/deletion, inline text edits, title undo/redo, layers, zoom/fit/pan, grid/snap, and invalid numeric input. Layout regressions cover tier separation, output order, centering, import-order determinism, and clear label/heading space.

Existing regressions additionally cover drag/drop performance, resize and route handles, reconnect/Escape, topology projection, Unplaced placement, Auto-layout preservation, Re-layout All undo, keyboard bindings, save/load, validation jumps, generation interlocks, revision bundles, and searchable vector PDF/SVG profiles.

Riverside is inspected read-only. Its occupied MSP LX500 port and unresolved routing contacts remain warnings; this release does not reinterpret its wiring or merge differently named physical locations. Synthetic simple, branched, and seven-RSP fixtures supplement the visual review. Windows mouse interaction is not verified on this macOS host; automated GUI checks are not a substitute for that release check.

## Local release checks

Before installing: run the full suite, inspect rendered samples, verify the native build signature/version, and confirm the installed app is closed. Retain the prior native bundle as a recoverable backup. Roll back if project opening, editing, saving, or export fails; do not overwrite user sessions during verification.
