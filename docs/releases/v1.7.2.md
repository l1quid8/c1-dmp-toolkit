# C1 DMP Toolkit 1.7.2

## Changes

- Edit keypad device numbers while preserving wiring, riser placement, locations, and RemoteLink settings.
- Remove the worksheet-only Global keypad checkbox from keypad editing and creation.
- Preserve splitter output locations and larger LX splitter inventories during worksheet round trips.
- Recognize more field worksheet splitter names and input capitalization without introducing duplicate panel feeds.
- Improve spacing in dense riser presentations.
- Identify zone descriptions RemoteLink cannot encode and prevent generation when the preview fails.
- Correct an OCR misreading of the east-direction marker in zone descriptions.
- Prevent replacing the installed macOS app while it is running.

## Validation

- Local regression suite: 1,047 passed, 6 skipped before the checkbox removal.
- Focused hardware and keypad tests after removal: 40 passed.
- Final non-GUI regression run: 793 passed, 260 skipped (including GUI tests).
- Native macOS app rebuilt, installed, and launched successfully.
- GitHub release automation runs macOS and Windows regression checks before packaging both platforms.
- Interactive Windows testing has not been performed locally.

## Compatibility

Existing project files retain their saved Global keypad worksheet value. The checkbox has been removed from the UI; project data is not discarded.
