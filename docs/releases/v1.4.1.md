# v1.4.1 — Riser editing corrections

- Interactive wiring rejects occupied input and output ports. Imported wiring conflicts remain visible and project to explicit conflict text, consistently across cards, saves, and worksheets.
- Location typing coalesces redraws. Presentation edits no longer rebuild other tabs, and unrelated changes preserve drawing undo history. External topology changes still reset history so undo cannot resurrect removed wiring.
- Recent-project discovery runs in the background, so a slow or unavailable project folder cannot block the home screen. Late results are discarded when leaving that screen, and repeated visits reuse an in-flight scan.
- Dropdown redraws no longer re-enter Tk's layout loop. A full-application project-open regression covers the resulting macOS freeze, in addition to the existing scrollbar checks.
- Only the active editor tab is mapped to native windows. Inactive tabs retain their widgets and editing state without participating in the macOS expose/layout churn that stalled full-project opening.
- Devices have persistent location ownership. Overlapping frames cannot move another room's devices. Assigning a location preserves existing device coordinates and routes; placement warnings identify devices that still need moving into their assigned module.
- Canvas and vector exports share device shapes, label geometry, title-block layout, and bridge curves. The canvas uses the embedded C1 logo and export text baselines.
- Project schema 4 saves location ownership. Schemas 1–3 remain readable; older applications reject new saves. Retain original project copies when an older app is still needed.

Validation covers assign/rewire/move/undo/save/reopen/export sequences for branched, three-RSP, and seven-RSP/two-wing fixtures; occupied-port rollback; imported conflict projections; refresh isolation; and canvas/SVG geometry parity.
